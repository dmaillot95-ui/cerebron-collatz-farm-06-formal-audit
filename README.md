# CÉRÉBRON Ω — Collatz Farm 06 Formal Audit

Ferme indépendante d'audit formel du programme Collatz CÉRÉBRON Ω.

Mission: vérifier les preuves, quantificateurs, dépendances, passages local→global, exactitude des congruences, portée arbitrary-N et distinction calcul/simulation/preuve.

Règles absolues:
- REALITY > COHERENCE
- EVIDENCE > CONFIDENCE
- CLAIM <= EVIDENCE
- SIMULATION != TEST
- FINITE CHECK != PROOF
- LOCAL REALIZABILITY != GLOBAL CYCLE
- CONSENSUS != TRUTH
- CYCLES OPEN sauf contradiction universelle démontrée.
